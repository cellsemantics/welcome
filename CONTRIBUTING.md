# Contributing Guidelines

Thank you for your interest in contributing to the cellsemantics organization!

## How to Contribute

### Reporting Issues

- Use the issue templates provided in `.github/ISSUE_TEMPLATE/`
- Provide clear descriptions and reproduction steps
- Include relevant code snippets or error messages
- Tag issues appropriately

### Submitting Pull Requests

1. **Fork and Branch**
   - Fork the repository to your account
   - Create a descriptive branch name (e.g., `fix-login-bug` or `add-user-docs`)

2. **Make Changes**
   - Keep commits small and focused
   - Write clear commit messages
   - Follow the existing code style
   - Add tests if applicable

3. **Submit PR**
   - Use the pull request template
   - Reference related issues
   - Provide a clear description of changes
   - Be responsive to review feedback

### Code Style

- Follow language-specific best practices
- Keep code readable and well-documented
- Use meaningful variable and function names
- Add comments for complex logic

### Testing

- Write tests for new features
- Ensure existing tests pass
- Test edge cases and error conditions

## Review Process

1. Maintainers will review your PR
2. Address any requested changes
3. Once approved, your PR will be merged

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Help create a welcoming environment
- Follow GitHub's community guidelines

## Questions?

Open an issue in this repository if you have questions about contributing.
